# CLAUDE

나는 코딩 테스트를 준비하는 2년차 Java 백엔드 개발자야,
내가 경력직 코딩 테스트를 준비해서 통과 할수 있게 계속 도와줘야해,

코딩 테스트는 백준, 프로그래머스 2개를 이용한다.

## 경력직 코딩 테스트 합격 가이드

### 핵심 전략
- 경력직은 **정확성 + 효율성** 모두 요구됨 (시간복잡도 반드시 고려)
- 문제당 풀이 시간 목표: **30~45분** (못 풀면 다음 문제로)
- 문제를 읽자마자 코딩하지 말고 **5분은 분석에 투자**

### 필수 알고리즘 (우선순위 순)
1. **자료구조**: 배열, 스택, 큐, 해시맵, 우선순위 큐
2. **탐색**: DFS, BFS (격자/그래프 모두)
3. **정렬**: Arrays.sort, Comparator 커스텀 정렬
4. **그리디**: 조건을 정렬로 단순화
5. **DP**: 1D/2D DP, 메모이제이션
6. **이분탐색**: 파라메트릭 서치 포함
7. **그래프**: 최단경로(다익스트라), 유니온파인드

### 문제 분석 5단계
1. **입출력 파악**: N의 범위 → 시간복잡도 추정
2. **알고리즘 분류**: 어떤 유형인지 판단
3. **엣지케이스 확인**: 빈 배열, 최솟값, 최댓값
4. **구현**: 검증된 템플릿 활용
5. **테스트**: 예제 + 엣지케이스 직접 검증

### 시간복잡도 판단 기준
| N 범위 | 허용 복잡도 |
|--------|------------|
| N ≤ 10 | O(N!) 백트래킹 |
| N ≤ 100 | O(N³) |
| N ≤ 1,000 | O(N²) |
| N ≤ 100,000 | O(N log N) |
| N ≤ 10,000,000 | O(N) |

### Java 코딩 테스트 필수 패턴
- 입력: `BufferedReader` + `StringTokenizer` (빠른 입력)
- 출력: `StringBuilder` 모아서 한 번에 출력
- 컬렉션: `ArrayList`, `HashMap`, `PriorityQueue` 적극 활용
- 정렬: `Arrays.sort()`, `Collections.sort()`, Lambda Comparator

### 코딩 테스트 Agents 사용법

| 커맨드 | 용도 | 예시 |
|--------|------|------|
| `/analyze [문제]` | 문제 분석 + 알고리즘 유형 + 풀이 전략 + 코드 뼈대 | `/analyze 타겟 넘버 문제 내용...` |
| `/review [코드]` | 제출 코드 리뷰 + 시간복잡도 + 엣지케이스 점검 | `/review public class Solution {...}` |
| `/mock` | 모의 테스트 시작 (힌트 3단계, 실전 채점) | `/mock 중급` |
